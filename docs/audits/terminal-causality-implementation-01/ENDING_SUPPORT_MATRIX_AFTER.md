## Resolution rule

For hard-gate-legal candidates in the locked Proposal family:

`resolutionScore = primaryStrength + priorityTier + effectiveSupport`

- primary exact = 4; approved adjacent Cosmic compatibility = 2;
- family-local priority tier = 0..4;
- support = at most three inputs, capped at 6;
- fewer than two independent domains ⇒ effective support 0;
- deterministic ties: existing priority, then Ending ID.
