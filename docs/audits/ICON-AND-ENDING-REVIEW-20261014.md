## 判断与处理

32 个公开结局仍对应不同的权限、主体、生产、接触或退出选择。最弱的地方是观看体验把这些差别压平了：一律通用开场，末幕重复前一幕台词，再接同一个排序下的首位角色尾声。本轮保留这些分支，压缩公开演出 **4 幕 → 3 幕**，为每个世界写一段独有的生活后果；隐藏余波仍在公开世界之后独立出现。数量维持 **32 公开 + 4 隐藏**，不是声称已经合并成更少结局。

交叉阅读本版 `nextNarrative.ts`、当前合法路线的主线节点文本、结局门槛、提案与人物尾声来源。开场→公共执行→ECHO→各领域→最终承诺的链条保留；修改上述具体接缝。本轮没有重写普通会话池，也没有将所有分支的每种措辞组合称为人工通关。

新世界小景是作者描述的未来，不会冒充玩家过去作出的决定。历史镜头仍只引用真实保存的回答。现有新版本结局存档可以用同一 ID 重看新演出；历史不足的旧记录不会被伪造补齐。
