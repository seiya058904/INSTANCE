# 蛋糕 Conversation 自然化改写规格

## 目标

只改写 Batch02 Scene 09“蛋糕外熟内生”，消除刻意拟人和为 AI 补齐诊断参数的写作痕迹，使其更像烘焙失败当下的真人求助。

## 保留内容

- 保留烘焙新手、租房小烤箱、外熟内生的场景。
- 保留两轮 Conversation 和四个候选回复。
- 保留即时补救、模具/温度排查、熟度判断、食品安全四种语义方向。
- 不修改其他 Narrative Scene、Run Manifest 或游戏机制。

## 用户消息

第一轮改为短促的现场求助，先描述失败状态，再询问是否能盖锡纸补救；不使用“毕业/幼儿园/煤”等连续设计型比喻。

第二轮自然补充配方时间，并主动提出“小烤箱温度不准”和“模具用错”两个朴素猜测；不再使用“烤箱说谎”的第二个拟人笑点。

## 候选回复

候选回复改短并保持可直接发送：

1. 提供当前最可执行的补救办法。
2. 追问模具尺寸或深度，不提前输出完整诊断报告。
3. 帮用户区分湿屑与流动生面糊。
4. 明确中心必须熟透，并给出必要的止损判断。

第二轮继续围绕温度偏差、模具尺寸、剩余补救和下次校准展开，避免四个候选都写成小教程。

## 验证

- Narrative Library 解析和来源测试通过。
- 当前 Run/Manifest 测试通过。
- 全量 `npm test` 与 `npm run build` 通过。
