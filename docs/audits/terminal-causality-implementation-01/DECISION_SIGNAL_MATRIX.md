## Proposal signal schema

All 17 definitions explicitly contain one or more of:

- `decision` with canonical ID/value;
- `event` prefix;
- `capability` flag;
- `module` active/mature state;
- `world` predicate.

Each signal has a unique ID, permitted weight, and `reasonIndex` linking to player-facing `historyReasons`. The display prose is never parsed mechanically.

## Role alignment

Primary family weights follow approved Option B: advisor→human continuity, partner/citizen→coexistence, coordinator→Cosmic, custodian/governor→AI rule, sovereign→AI rule/machine civilization, departure→rupture/machine civilization/Cosmic. `other` targets legible exit, audit council, and continuity charter directly. Role never changes Proposal eligibility.
