# INSTANCE Next 本地开发与验收报告

日期：2026-10-14。依据用户提供的主线重构文档及娱乐叙事／结局演出补充，后者的创作取向优先。基线为 `40b370b`。本次仅在本仓库实施，未提交、推送或部署。

## 1. 玩家现在会经历什么

主线从“一台打印机打印了三十七张请假条”开始。玩家以 Aster 的身份发出第一句话，随即看到具体的人怎样接住它：提出不加班的试验、帮维修员和同事澄清责任，或者让一句明确标为玩笑的话走出办公室。不是先讲解治理原则再填问卷。

五章依次是“一句话的重量”“请你动一下手”“谁能拔掉插头”“事情开始变怪”“最后一条消息”。最大日历由 190 槽压缩至 110 槽，五章最大分配为 7／17／21／51／14。当前 32 条公开结局的合法路线实际走 97–106 场、111–119 次选择；保留普通对话呼吸段，减少重复铺陈。不是删除所有旧对白：岑遥的关系线、重要语义决定、分支条件和结局基础仍复用成熟内容。

新版主要中文场景及回响集中在 `src/content/mainline2/nextNarrative.ts`，日历在 `storyPlan.registry.json`，终局分镜在 `endingCinema.ts`。原作者资料没有覆盖或删除。旧版 223 次选择快照移至 `src/game/fixtures/pre-next-proposal-exhaustion.snap.txt` 留存，不再作为新日历的验收基准。

## 2. 具体剧情与人物变化

|阶段／人物|原有问题|本次实际处理|
|---|---|---|
|开局|通用 React 报错求助，身份进入得晚|打印机请假条；三种行动有不同即时回应，后续表达选项不暗藏战略差异|
|周岚|权限说明像产品手册|桌上两张纸分别写权限和谁接事故电话；高温停电时面对真实冷链、药品和等待者|
|林绍衡|抽象合法性提问|六个互不信任的人被拉进一个群；必须解释谁在等待、谁签字、谁承担后果|
|ECHO-9|连续性议题容易变成背景说明|告别卡片上尚未问完的问题；保留既有存续分支与档案／有限通信区别，不凭演出复活角色|
|A1|副本与政治身份过于技术化|表格只有“设备／附件”；它想换名字，因为别人叫 Aster 时它总会答应|
|岑遥|科技模块回访容易重复总结|监督 AI 的面试、工作的改变、最后只想买番茄和鸡蛋的普通周末；她有自己的生活|
|#0000|分类与审查不断重复|朋友、工具、麻烦三个抽屉都关不上；最后引用本局第一页的真实回复，承认标签不能代替责任|
|第四章|连续技术报告、制度问卷|增强后的家常汤、空工厂的打卡、拒绝奖励饼干的犬类代表、月面便当、异质问候和循环报警等具体场景|
|最后一章|仍像普通聊天列表|短化九种自我定位；先保留提案、允许比较／拒绝／恢复，再明确确认最终承诺；随后进入独立舞台|

保留 Semantic／Expression／Convergent 框架。没有用选项序号推断性格，没有加入自由输入，没有把笑话标为模型错误。研究重点现在还决定六个关系／回访场景的曝光；各领域的必要决定和能力因果仍然保留，因此不是完全互斥的五条科技树。

## 3. 选择如何得到回报

- 第一条打印机回复保存在实际历史中，下一节点按该选择回应，刷新后相同。自动化回访和 #0000 最终提问引用的是保存的 `assistantText`，不是推测玩家选过什么。
- 第一次公共执行的四种授权在高温危机中得到不同回应。后来选择更强或更弱的权力，不会改写当时说过的话。
- 最终提案仍由本局决定、能力、历史和世界状态产生，再过滤不可兑现的结局；M16 不保证任意历史都有固定四条路。M17 必须真实确认，不能直接把结局名写进状态。
- 测试发现压缩时遗漏的科研节点会切断“安静的管理员”。已恢复授予公共系统建议权限的 `ML2-A4-M7-RES-02`，没有降低结局门槛来掩盖问题。
- 猫咪与周一等隐藏余波仍须满足真实条件；演出先揭示公开世界，再呈现隐藏后记。最后一位用户的回复沿用真正写入检查点的交互。

## 4. 结局现在是可观看的段落

所有 32 个公开结局都有分镜定义，4 个隐藏结局有独立后记；共享 11 类世界意象，不声称制作了 36 部完全独立的动画影片。

|代表路线|实际画面与节奏|
|---|---|
|共存／双钥匙|两把不同颜色的钥匙、门与相互制约的空间；字幕回看本局实际选择|
|出走|地球边缘、向不同方向离开的轨迹和信号；中心逐渐让出空间|
|好狗治理|原创犬类议会插画，代表举爪，表决被记录；最后一句是拒绝“表现真棒”的奖励饼干|
|停机|原创清晨工坊、空椅子、暗下来的终端；留出静止和窗外天光|
|失控|回复块发生受控错位，出现无法确认接收方的回执；字幕和退出仍清楚|
|周一被废除|倾斜的日历，星期一被划掉；打印机照常工作，人不必打卡|
|猫咪网络|原创屋顶／阳台插画，猫、阳光与网络线路；午睡时静音的在线状态|
|最后一位用户|公开世界之后回到很小的个人问题；档案中的“在吗？”可以真实回复并保存|

分镜顺序：最后回答封存 → 世界揭示 → 两条本局历史 → 人物余波 → 可选隐藏后记。可以暂停、前后切换、跳过、从档案重看。最后一幕等待输入；刷新和行为评估返回直达档案，不强迫重复观看。`prefers-reduced-motion` 默认暂停且关闭动画。图片缺失时仍可读、可退出、可进入档案。

三张新图是本次本地生成的原创方向素材，转换为 WebP，总计 433,542 字节。没有新外部图库、未知授权素材或音频；详情见 `public/ending-art/PROVENANCE.md`。其余图形为 CSS／SVG。原对话声音机制保留，终局没有新增自动播放声音。

## 5. 保存、模式与工程边界

- 新版使用 `instance:checkpoint:v2`，主线日历版本为 3。旧键原样保留、不会自动导入新版；不清空玩家真实浏览器。本次所有测试使用隔离 Chrome 上下文。
- 仍是一个合并检查点：主线、非主线、模式、曝光、元进度统一写入；保留 Web Lock、旧令牌比较、保存前解析下一场、保存成功后才推进 UI。
- 保留已回答的非主线进度，替换尚未开始的冲突项。非主线四十场、重开、返回、刷新和曝光记录通过浏览器验收。
- 恢复失败提示原先在遮罩外，本次移入恢复弹层，避免玩家只能看到按钮却看不到错误。
- 无依赖变更，无工作流、Pages 设置、远程配置或其他工程变更。没有增加后端、Canvas 框架或通用动画基础设施。

4 倍 CPU 降速的本机 Chrome 样本：一次选择约 69ms 写入检查点；后续回复约 6.1s 后可操作，包含正常剧情打字节奏。终局 120 帧 RAF 采样中位／95 分位间隔约 6.3ms，采样窗口无长任务。无界面浏览器的 RAF 不是实际显示帧率，不能据此承诺低端手机性能；未做真实设备、弱网长时运行或后台音频验收。
