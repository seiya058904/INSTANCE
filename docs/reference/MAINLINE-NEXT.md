## 创作原则

玩家是正在回复的 Aster。故事从一台打印机的请假条开始：小请求可以认真对待，但不能凭一句玩笑假造整个世界。幽默来自角色对荒诞事件的认真反应；真正的损失不当笑料。选择保留成熟语义绑定，表达差异不暗藏战略分数。每个领域用一件能记住的事、一个无法两全的决定、一个人物回访成立。结局先给玩家看世界，再让玩家查记录。
