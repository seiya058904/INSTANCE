## 序列与回看

世界揭示 → 本局两个已保存关键选择 → 具体的后来（停留）→ 可选隐藏尾声（停留）。首幕按情绪 8–11 秒；回声最少 8.5 秒，按字符数增加阅读时间。全部分镜可用按钮重访；尚未看到世界末幕时余波入口不可用。手动导航暂停自动播放，减少动态效果默认暂停，页面转入后台也暂停。

收藏展示 32 个公开世界中的已解锁部分；旧 meta.completedEndings 只有英文标题，不能恢复过去局的完整演出或隐藏尾声，因此旧局只看作者未来场景。无解锁剧透墙、无假存档、无新永久存储结构。
