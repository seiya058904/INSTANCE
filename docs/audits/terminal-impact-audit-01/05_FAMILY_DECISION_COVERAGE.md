## Concentration findings

- `cascade_authority` is the most centralized Decision: 8 endings across 3 families.
- `contact_doctrine` is a single Decision switch for all 5 cosmic endings.
- Posthuman and security each use only one Decision ID across their entire family; cosmic is even more concentrated because it contains 5 endings.
- `echo_existence`, `contact_disclosure_doctrine`, and `aster_intended_role` receive zero Public Ending family coverage.
- `offworld_governance` is recorded for routes such as Exodus, but its value is not checked; any canonical value satisfies the prefix history gate.
- `act4_research_emphasis` has zero direct ending coverage but high indirect coverage through module activation/maturity and capabilities.
