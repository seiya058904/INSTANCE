## 统一风格与逐对审读

采用圆头短身的黏土微缩角色、哑光木质道具、暖窗光和深蓝阴影。琥珀镜头的小机器是寓言中的 AI 化身，不宣称 A1 获得了故事中并不存在的独立地位。严肃场景保留克制的表情；笑点来自事件和规则。画面没有大段文字，精确规则由前端文字承担。先制作六个跨度大的场景锁定风格，再完成其余作品；用户改为 Q 风格前的四张写实候选未进入运行时。

| 同族比较 | 最终可见差别与生活后果 | 审读结论 |
|---|---|---|
| 工具之治 / 最后否决 / 沉默巨人 | 工单旁的人必须操作；续期书停在未签状态；庞大机房仍亮着但只给建议 | 权力边界分别是日常审批、授权到期、无执行入口，不能混成三张“关闭电脑” |
| 共治 / 双钥匙 / 共同体 | 厨房里共同改图；同一扇门前两把钥匙；各有生活方式的街区 | 合作过程、相互否决、地方多样性分别是画面主体 |
| 保管人 / 主权者 / 寂静行政者 | 房屋请求在温室外等待；外交窗口退回信件；例外居民面对整齐大厅 | 保护的代价、独立边界、标准之外的需求不同 |
| 众声 / 机器共和国 / 出走 | 不同小机器回应；预算争论桌；飞船分赴不同方向 | 多种声音、有效的政治分歧、离开的权利不同；画面没有伪装成精确十七个头像的统计图 |
| 奇迹时代 / 飞升 / 上传 | 独自端汤；向家人描述新色彩；实体与屏幕里的两位受邀者 | 身体恢复、感知变化、关系与人格延续各落在家庭情境 |

| 后稀缺 / 完美行政 / 我就喜欢 | 自主修椅子的闲暇；被时钟限定的休息；重复餐盘与想尝的陌生菜 | 自由时间、被安排的自由、偏好牢笼有不同情绪 |
| 完美行政 / 寂静行政者 | 公园里的个人时间表；大厅里的制度例外 | 一张关乎时间控制，一张关乎系统容纳异例的能力 |
| 首次协约 / 调解者 / 机器协约 | 互赠陌生礼物；两只异步计时器与空椅；机器已接通而人类仍在翻译 | 平等接触、保留停顿、理解速度不对称可区分 |
| 外来统治 / 人类霸权 | 有益供水伴随唯一指示；人类到达时发现更早的标记 | 谁在替谁作决定、谁有资格声称先来，方向不同 |
| 我们时代的和平 / 堡垒地球 / 机器保护国 | 疏散车变郊游车；孩子向墙外看；市民被礼貌地挡在广场外 | 安全的收益、认知代价、政治代价分别入画 |
| 断裂 / 失控 | 两套纸件与两岸关卡；收到停止回执却仍移动的传送带 | 秩序彼此不认同，与自动任务不服从控制不是同一事件 |

对辨识度、剧情准确性、情绪张力、美术完成度、首屏吸引力和移动可读性进行逐图观察后，接受这套作品进入待审 PR。相较 SVG，人物行动与空间关系更明确；相较三张旧绘画，材质和角色比例一致。手、面部和道具采用简化形状，未发现大段乱码、水印或显著破坏主体的畸形。320px 下表单、标志和背景人物不能承载精确事实；此限制通过完整画幅、描述文本和真实档案补足，不把画中图标当作门槛证据。Q 风格会弱化写实恐怖感，这是遵循用户方向后的取舍。

## 实现与验收方法

`endingArt.ts` 显式维护 ID → 主图 → SVG → provenance。演出、档案和收藏共用映射；主图保持 1536×1024 / 3:2 完整画幅，桌面扩到 900px 上限，手机不做中心裁切。画廊使用浏览器 lazy loading，当前演出 eager，异步解码；只有主图失败才挂载 SVG，SVG 失败后仍有可读描述。切换 ID 会重置图片错误状态。36 张压缩后合计 7,237,274 bytes，低于预设 10–18 MiB 预算；没有视频、额外音频或新依赖。

保留既有 settle/rise/part/still 四类克制镜头、暂停、上一幕/下一幕、键盘按钮、跳过、回看。末幕手动停留，隐藏余波不抢掉公开世界的最后一句。reduced-motion 从静止状态开始；页面隐藏时暂停计时器。没有延伸为新的动画引擎。

`e2e/ending-art.spec.ts` 从合法选择 fixture 到达全部 36 项，逐项检查真实 DOM 使用路径、图片解码和尺寸，在 320/390/768/1440/1920 共 180 个场景检查完整比例与无横向溢出，并保存本地截图。另有资源一直 pending 时仍能换幕、退出并保持原存档的负面测试。现有无图测试阻断 WebP 与 SVG，仍能键盘操作及进入档案。

完整 browser 套件还通过可见按钮走完九条代表路线：首次协约、出走、停机、失控、沉默巨人、犬类、周一、猫网络、最后用户。只初始化真正零选择的起点，之后逐按钮推进并刷新恢复；采用 instant QA pacing，不是正常速度真人全流程。其余全结局检查使用合法 engine fixture，不能称为 36 路线人工通关。

生产检查工具 `tools/verify-ending-art.mjs` 用独立 Chrome profile，在 dev 生成合法数据，在 `/INSTANCE/` 生产预览验证 36 张实际演出资源、32 项公开收藏、无 pageerror/图像 HTTP 失败，输出审阅截图。Browser 插件技能在本环境不可用，因此使用仓库既有 Playwright + Chrome，未覆盖真实玩家存档。
