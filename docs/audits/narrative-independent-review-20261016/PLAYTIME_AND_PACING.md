# 游玩时长与节奏：文字模型及浏览器校准

**普通认真阅读首次一局约 90–120 分钟，中心约 100 分钟；快读约 65–85 分钟；细读与认真回看约 140–175 分钟。** 这是本轮实际可见文字与 Chrome 行为支持的阅读模型，未经过独立真人通关验证。七线原配方的普通模型点估计为 95–107 分钟，付费转向样本可达 114 分钟；玩家差异大于大多数深线差异。

## 统计的到底是什么

从 edition-4 catalog 重新执行每个合法选择，读取每次 resolveScene 返回的实际动态 userMessages（存在时替代 userMessage）、内容附件、长输入预览、**全部当前候选**、选后新增展开回复、首次进入对话时的实际 User 标签。最后读取当前 endingCinema 与 buildEndingArchive 的电影字幕、承诺、关键历史与人物后记。没有累计未遇分支、作者 Markdown 全文、隐藏在源代码里的另一种结果；也没有按 .ts 文件字节数估时。

选中回复已经在候选中读过，普通发送/历史区重显不再算新文字；澄清操作的保存 assistantText 不同于按钮标题，单独加入。M17 同一节点的回看/澄清再次呈现用户段落与变化后的候选，计入重读负担；engine 只把该用户原文存一次，因此不能拿存储历史的去重误称 UI 不再出现。档案主动要求重新核对的历史原话仍计入；模型里包含电影与档案重复，是“看完结局材料”的情景，不是最短关闭窗口时间。

原始字数＝上述剧情字段的非空白 Unicode 码点，含中文标点、拉丁字母、数字。阅读折算单位＝每个汉字 1，连续英文词/数字 token 1；标点不另加阅读单位。例如 Aster 记作 1，1042 记作 1，而非四个汉字。统计精度可复现，阅读折算并不是心理学实测。中文标点不计入模型会略低估停顿，因此另有思考/回翻项。折叠长文按展开阅读计数，遇到它的普通插槽存在小幅上界偏差。通用界面按钮、反复出现的页脚、插画题签、收藏架再次显示同一结局的预览不另当新增剧情；这不是整个 DOM 的字符普查。插画独有题签有少量未纳入字数的文字，故绝对可见总量仍有小误差，不影响按分钟给出的估计。

36 条目录轨迹为 **105–121 次提交、92–104 个会话**；可见原始非空白码点 **30,163–34,819**，阅读折算单位 **26,045–30,092**。这里的“场景数”按一次呈现/提交计，含 M17 同节点的多次交互，不等于唯一 nodeId 数。数字只针对这些配方，不声称所有随机普通聊天的全局最短/最长。

## 模型、重叠与敏感性

令第 i 段来信阅读为 H/r，其他新文字（当前全部选项/必要新增回复/标签）为 O/r；正常 UI 从上一点击到来信开始的串行时间为 A（发出回复、交接、输入前停顿、特效），来信流式时间为 S：

> T_i ≈ A + max(H/r, S) + O/r + 思考 + 操作 + 回翻。

这不是“字数阅读时间 + 所有动画时间”。来信可边出现边读，用较长者；已读过的选中回复不再增加阅读字数，只在实际串行挡住下一段时计 UI 时间。出现/按钮可用先后以 conversationFlow.ts、timing.ts、App.tsx 和本轮正常样本校准。第一段恢复时为静态；不人为给每条加固定首屏加载等待。结局演出可立即手动推进/跳档案，未把自动镜头计时机械加到读字之上。

## 二周目、七线与收藏

没有章节快进，因此下面只假设**人工略读**：已经逐字见过且节点/来信/全候选完全一致的正文，以 1200 单位/分扫读；新段仍按 360 阅读，生产 reveal/交接照付。普通熟悉选项思考按原先的 35%，旧段回翻 1%。不是实现了隐藏的跳章功能。

合计约 6.7 小时；扣掉首次，体验其余六线约 **5–7 小时额外投入**。顺序、普通聊天重抽和记忆程度会改变结果。第二局约 **45–70 分钟**较合理；如果坚持每局全文精读，七次则约 **11–14 小时**。七线不是互斥到只保留 1/7 内容，路线共享量很高。

一个结束的 run 只能给一个公开世界，同时最多一个优先级胜出的隐藏余波。因而看全 32 世界的理论下界是 **32 次结束**；四种余波可配在其中的不同局，目录本身已给共同体/最后用户、出走/离岗、我很喜欢/周一、无主地球/猫的配对。32+4 不是必须 36 次，也不是四个余波可以在一局全显示。收藏架只永久保存公开世界名称，历史隐藏余波不重建；要自行保留尾声截图/导出才便于个人核对。

以原目录顺序完成 32 个公开配方、熟悉文本按上面的人工略读模型计算，合计 **26.25 小时**。加上四余波的计划、正常回翻和路线核对，合理说明是**有路线信息、少走错路的收藏约 24–32 小时**；若各余波另开四局，约再加 3–4 小时。不是玩家盲玩实测，也不是最优解证明。隐藏触发包括个人尾声事件、离开中心的身份且稳定结算、后稀缺经济原则、可靠通信与猫频道桥，且有覆盖优先级；盲玩可能反复错过，**没有足够证据给出可靠有限上界**。

全收集的长度与新增戏剧量不匹配：普通推荐读一局，再换一至两条深线。32 结局适合愿意做反事实比较的收藏者，不应以它要求所有读者完成 20 多小时重复聊天。

## 节奏编辑与可靠性

最值得压短的是终局同文候选、已完整回执在回访里的再次整段粘贴；保留当事人后续改变，少复述“没有改写”。不建议加快 ECHO 的第五项、妻子的不同意和停机接线员镜头，这些停顿正是作品的内容。第四幕各领域的共同菜单若未来维护，可先删一句重复解释，不要用更多角色替系统补课。

文字统计与合法路径的置信度较高；普通 reading speed、思考秒数、人工略读的置信度中等偏低，需要真人验证。隔离 Chrome 桌面/390px 有实测；无物理手机、真人完整自然阅读、眼动/理解正确率测试。没有将 QA instant、单测耗时或旧报告“2.7 分钟浏览器测试”用于估时。精确数据来自 temp 下 extract.mjs、model.mjs；它们只写本轮 temp，没有运行会覆写旧证据的原生成器。
